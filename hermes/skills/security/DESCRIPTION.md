# Security

This skill category is dedicated to cybersecurity investigation and forensic analysis within the VIGILANT ecosystem.

It provides specialized capabilities for:
- **Network Traffic Analysis**: Secure inspection of packet capture files (`.pcap`, `.pcapng`) through ingestion and quarantine processes.
- **Anomaly Detection**: Identification of suspicious protocols, irregular IP-MAC relations (such as possible ARP spoofing), and other network indicators of compromise.
- **Forensic Investigation**: Tools to break down and summarize network activity detected in security incidents.
